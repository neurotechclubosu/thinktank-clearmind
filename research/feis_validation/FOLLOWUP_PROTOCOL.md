## FEIS signal and task audit

Use all 21 English participants, native 256 Hz and the declared 14 channels. Accept timestamp differences up to 1 microsecond, the previously demonstrated decimal-rounding tolerance, without accepting gaps or resampling malformed records. Verify original downloaded hashes. Retain the original later-block split: first floor(0.7 * blocks) training, remaining blocks test. All phases from the same trial remain on the same side. Full recording participant01 supplies stimuli and speaking diagnostic phases; these are one-person controls, not cohort evidence. Rest follows speech and can contain carryover.

Report raw channel spectra, 50/60 Hz fractions, flatness, amplitudes, native flags, timestamp/phase boundaries, trial label consistency, and trial-order patterns. Physical units/acquisition reference and direct eye/mouth signals are not independently established. Artifact features (log peak-to-peak, channel means, supplied flags) receive the same training-only model selection and test split. Their success limits a neural interpretation; their failure does not demonstrate absence of artifacts.

## Two fixed baseline families

For both: remove per-trial DC, common-average reference, 50 Hz Q30 notch, fourth-order 1-45 Hz Butterworth, crop the central four seconds, then resample to 128 Hz. Filter original phases separately before cropping; no boundary across trials. Preprocessing is fixed and does not fit a parameter across test trials. Also report the existing five-band mean-power LDA at this bandwidth for context. Primary screening excludes malformed/nonfinite/completely flat records. Prespecified strict sensitivity uses the existing training-only amplitude/flatness/flag rule; keep all exclusions and class coverage.

1. **Filter-bank log-covariance + ridge logistic regression.** Five bands [1,4), [4,8), [8,13), [13,30), [30,45) Hz. Covariance per trial, shrink 10% toward trace-scaled identity to handle common-reference rank loss, matrix logarithm, upper triangle with sqrt(2) off-diagonal weighting. StandardScaler fitted only on training. Logistic C candidates 0.01, 0.1, 1, max_iter 1000. This is a log-Euclidean covariance representation, not a claimed affine-invariant Riemannian tangent-space estimator.
2. **Compact EEGNet-style temporal-spatial CNN.** F1=8, D=2, F2=16, temporal kernel64 at128Hz, spatial depthwise convolution, separable temporal convolution16, pooling4 then8, ELU, dropout0.5, Adam lr0.001/weight_decay0.0001, batch32, cross-entropy, spatial-filter max norm1 and classifier max norm0.25. Candidate training lengths30 and60 epochs. Channel RMS scale is estimated on training only. Architecture adapted from [Lawhern et al. EEGNet](https://arxiv.org/abs/1611.08024); this implementation is not the authors' exact implementation, and their original validation is not imagined-speech validation.

Select C or epoch count by the mean balanced accuracy of two expanding chronological validation folds entirely within training: train preceding blocks, validate each of the last two training blocks. Ties select smaller C/fewer epochs. The CNN uses seed17 for inner selection. Refit all training, evaluate seed17 as the primary CNN score; seeds29 and43 are stability sensitivities and are not independent observations. Do not change the architecture, filtering, feature family, budget or split after seeing scores. No cross-person or independent-session claim.

## Controls, uncertainty and decision

999 conditional test-label permutations shuffle labels within original held-out balanced trial blocks, separately by participant. Predictions are fixed and model selection used training only. Compare cohort mean scores to independently generated cohort null draws; apply Holm across the two primary model families for thinking. This conditional diagnostic assumes label exchangeability within blocks; it is not a substitute for acquisition randomization or artifact measurement. Additionally run nine full training-label permutation refits per family on pilot participant01 thinking, rerunning inner selection, with true test labels fixed (CNN seed17). This limited pilot control keeps the compute budget bounded; it is not a cohort training-permutation analysis. Nine draws are a coarse implementation/learning control, not a precise significance test. Report every result. Pilot scope was fixed after synthetic implementation tests and before any follow-up real-EEG score.

Bootstrap participants10000times for cohort means and differences, seed20261004. A provisional FEIS signal gate requires mean balanced accuracy at least8.25% (2pp above16-class chance), participant95% interval lower bound above6.25%, and Holm-adjusted conditional-permutation p<=0.05. This is a feasibility threshold, not a clinically meaningful endpoint. Review strict screening, rest and nuisance controls and CNN seed stability before attributing imagery-specific information. If no family clears the signal gate, do not run further FEIS splicing comparisons. If one clears it but artifacts/controls are concerning, report unresolved specificity and withhold an augmentation-benefit claim. Any subsequent augmentation plan must be saved before its results, and must preserve training-only donors and matched budgets.
