Response to Reviewers
We thank both reviewers for their careful reading. Below we address each point in turn. All quantitative changes are reproducible via scripts/reproduce_all.py in the code release; exact numbers and file/line references are given in docs/CORRECTIONS.md, docs/CONSISTENCY_ANALYSIS.md, docs/MODEL_VERIFICATION.md and docs/MANUSCRIPT_CHANGES.md, which this letter summarizes.

Reviewer #3
1. Quotation marks around “fractal”
Corrected. The Introduction sentence now reads “Using a self-similar (‘fractal’-inspired) brain model...”, aligning it with the “self-similar architecture” language already used in the Discussion. See docs/MANUSCRIPT_CHANGES.md, “Introduction.”

2. Synthetic-vs-real EEG consistency analysis
Added. src/analysis/consistency.py implements a full consistency analysis across the three domains requested: time-frequency (Hann-windowed periodogram shape and relative band power), source space (a validated, dependency-free spherical forward model with a depth-weighted, average-referenced dSPM inverse, since MNE/fsaverage could not be installed in our offline analysis environment), and metabolic metrics (CMRO2 on a shared reference scale). A leave-one-out real-vs-real baseline (n=44 source recordings) is computed so that synthetic composites can be judged against how similar real EEG segments are to each other, not against an arbitrary threshold.

Headline finding: the synthetic composites' CMRO2 spatial profile is statistically indistinguishable from real EEG (Spearman ρ 0.979-0.994, within or above the real-vs-real range of 0.835-0.988, for all three tested sentences and both conditions), while raw spectral shape (r=0.66-0.68 vs. real-vs-real range 0.94-1.00) and instantaneous source pattern fall outside the real-vs-real range. We report this honestly as a mixed result and revise the manuscript's realism language accordingly (see our response to Reviewer #4, point 1, below) rather than claiming general biological realism. Full numbers: docs/CONSISTENCY_ANALYSIS.md.

Reviewer #4
1. Central biological interpretation
Agreed, and revised throughout. Every instance of “enhances biological variability” (Abstract, Discussion, Conclusions) has been replaced with the demonstrated, narrower claim: microgap insertion significantly alters simulated EEG-derived metabolic outputs (quantified below), evaluated against the new consistency analysis rather than asserted as general realism. See docs/MANUSCRIPT_CHANGES.md for the exact before/after text of every changed sentence.

2. Statistical analysis and reported results
This point had four parts; we address each.
Unit of analysis: We no longer treat the 16 electrodes as n=16 independent replicates. The statistical unit is now the microgap realisation (R=2000 seeded draws per sentence); the montage-mean effect of microgap insertion is summarized by its mean, SD, a 95% CI, P(effect>0), and an exact Monte Carlo p-value across draws. Channels are additionally characterized, descriptively, as repeated measures via an effective-channel-count estimate (participation ratio of their inter-channel correlation), which came out to 1.3-2.1 of the nominal 16 across sentences and conditions — quantifying exactly how non-independent the channels are. See docs/CORRECTIONS.md, “Statistical unit of analysis.”

Dependence among derived outcomes: Quantified directly: pooling all analyzed windows and channels, the eight neurovascular variables have an effective number of independent variables of 1.01 (of 8), with the first principal component explaining 99.4% of variance. CMRO2 is now reported as the primary outcome; the other seven are labeled as derived, non-independent quantities in every affected table/figure caption. See docs/CORRECTIONS.md, “Dependence among the eight derived neurovascular variables.”

t=0.00 / p=0.00 / d=0.00 cells: Traced to two causes, both fixed: (a) the repeated-samples pipeline defect (our response to point 3, below) made every nominal “trial” identical, giving SD=0 and undefined t-statistics that were formatted as 0.00; (b) p-values were printed to two decimals with no floor. p-values are now reported with an explicit, never-zero floor (p_mc_floor = 2/(R+1)) and the “repeated trial” defect that caused (a) is corrected (below), so no table in the revision contains a 0.00/0.00/0.00 row.

Trial 2 p-value inconsistency: This was a transcription drift between a table regeneration and the Abstract/Discussion text, made possible because every prior “trial” was numerically identical (again, the repeated-samples defect). All manuscript numbers are now generated by one script (scripts/reproduce_all.py) directly into results/results.json, and every quoted statistic in the manuscript is traceable to one JSON field (docs/MANUSCRIPT_CHANGES.md gives the mapping), which prevents this class of error going forward.

3. Regenerate quantitative results using the corrected pipeline
Done. Three code defects were fixed in the public repository: (C-1/C-2) EEG_Implement_Welch.py analyzed the same first 1024 samples for every nominal trial and used an off-by-one trial index; (C-3) EEG_DistanceFunc.py weighted farther electrodes more heavily than nearer ones (inverted inverse-distance weighting) in the 3-D rendering path. A fourth defect not in the original public issue list, but required to obtain physiologically plausible numbers, was found and fixed during this revision: (C-5) a units mismatch that fed an absolute CMRO2 value into a model expecting a fractional change, which had inflated reported CMRO2 6-8x. All four are documented with before/after code, regression tests proving numerical equivalence to the pre-fix behavior under an explicit ‘legacy’ flag, and quantified impact, in docs/CORRECTIONS.md. Every table, statistic and consistency-analysis number in the revised manuscript is regenerated from this corrected pipeline by scripts/reproduce_all.py; 30 automated tests (tests/) check the corrections and their numerical equivalence to the legacy chain where applicable.

One caveat we disclose rather than paper over: CMUdict/g2p_en, used by the original pipeline for phoneme lookup, could not be installed in our offline revision environment. The numbers in this response and in the current manuscript draft use a probabilistic ARPAbet lexicon for the three test sentences (data/fixtures/trial_phonemes.json, provenance documented in its _meta field); scripts/reproduce_all.py --phoneme-source cmudict regenerates everything with the original lexicon source once that dependency is available, and we will do so before final submission.

We believe these changes directly address the reviewers' concerns about statistical validity, reproducibility, and the strength of the biological-realism claims, while being transparent about what the new consistency analysis does and does not show.
