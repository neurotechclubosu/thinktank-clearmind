# Synthetic-vs-real EEG consistency analysis

Requested by Reviewer #3, point 2: "Please supplement the experiments with a
consistency analysis between the synthetic EEG and real EEG across the
time-frequency domain, source space, and metabolic metrics." Implementation:
`src/analysis/consistency.py`; numbers regenerated by
`scripts/reproduce_all.py` into `results.json["consistency"]`.

## What counts as "real" here, and why a baseline is needed first

No continuous imagined-speech EEG of the three test sentences exists — the
source dataset (LaRocco et al., 2023) contains ~20 one-second repetitions
("epochs") of 39 isolated phonemes plus 5 auxiliary "microgap" recordings, one
participant, and the application always uses epoch 0 of each. A synthetic
composite therefore cannot be compared to "the real version of this
sentence"; there isn't one. What can be asked, honestly:

* **R1 - held-out redraws.** Fill the identical segment manifest (same
  phoneme/microgap recordings, same segment lengths, in the same order) with
  *held-out* epochs (1-18) instead of epoch 0. This asks whether the
  particular repetition the application happens to use (epoch 0) is a typical
  draw from the same phoneme, or an outlier.
* **R2 - real streams.** The 44 source recordings themselves, each taken as an
  unspliced, contiguous 19-epoch stream. This asks how similar a synthetic,
  spliced composite is to genuinely continuous real EEG from this participant.
* **Real-vs-real baseline.** Before judging "is the synthetic composite
  similar to real EEG", we need to know how similar real EEG is to *other*
  real EEG. `ConsistencyAnalysis.real_reference_distribution()` computes, for
  each of the 44 real streams, its similarity to a reference built from the
  other 43 (leave-one-out) — the same comparison pipeline used for synthetic
  composites, giving an apples-to-apples null distribution.

All of this is descriptive: one participant, one dataset, no independent
ground truth for the tested sentences. Findings should be read as "is this
synthetic composite typical of real EEG from this dataset," not as evidence
about speech-EEG in general.

## Reference bounds and features

A gamma-power reference scale shared by every recording is fixed once, from
the 1st-99th percentile of gamma power (30-100 Hz sum) over all 32-sample
windows of all 44 real streams: **[146.1, 1.53e7]** (arbitrary PSD units).
This is the `reference_bounds` scale used for the metabolic-metric comparisons
below, so that synthetic and real recordings sit on the same CMRO2 axis
(the application's own per-composite min-max scaling, used for its own
figures, is intentionally not used here, since that scaling by construction
makes every recording span exactly 2.1-3.1 regardless of its content).

* **Time-frequency**: 128-sample Hann-windowed periodograms, 50% overlap
  (`_segment_psd`); channel-averaged log-power spectrum 1-100 Hz (`logpsd`,
  compared by Pearson r and RMSE in dB) and per-band relative power in
  delta/theta/alpha/beta/gamma (`relband`, compared by mean absolute
  difference).
* **Source space**: a dependency-free, from-scratch spherical forward model
  (`src/analysis/source_space.py`) plus a depth-weighted, average-referenced
  dSPM inverse (lambda2=1/9), because MNE-Python and the fsaverage BEM used by
  the application's own 3-D visualizer (`src/viz/visualizer.py`) could not be
  installed in this offline sandbox (see the settings-comparison table in
  `source_space.py`'s docstring). The forward model is validated against two
  closed-form limits in `tests/test_distance_and_source.py` (centre-dipole
  potential, exact to 1e-6; near-boundary radial-dipole scaling). Compared
  quantities: Spearman correlation of the ~400-source dSPM power map (`_raw`:
  whole-stream covariance; `_dc`: per-epoch DC removed first, closer to what a
  trial-locked analysis would show) and the left-hemisphere power fraction.
* **Metabolic metrics**: montage-mean CMRO2 on the shared reference scale, and
  the Spearman correlation of the 16-channel CMRO2 *spatial profile* against
  the corresponding real-data profile.

## Real-vs-real baseline (n=44, leave-one-out)

| metric | median [range] |
|---|---|
| spectral shape, Pearson r on log-power (1-100 Hz) | 0.987 [0.941, 0.996] |
| spectral shape, RMSE (dB) | 3.02 [0.64, 9.12] |
| relative band-power, mean abs. difference | 0.024 [0.010, 0.136] |
| source pattern rho (raw covariance) | 0.942 [0.350, 0.986] |
| source pattern rho (per-epoch DC removed) | 0.868 [0.258, 0.939] |
| CMRO2 spatial-profile rho | 0.946 [0.835, 0.988] |

## Synthetic composites vs. this baseline

For each sentence, the composite actually produced by the application
(epoch 0, seed 0 for the microgap condition):

| sentence | condition | spectral r | source rho (raw) | CMRO2 profile rho |
|---|---|---|---|---|
| trial1 | no-microgap | 0.658 (0th pctile) | 0.449 (2nd pctile) | 0.988 (97th pctile) |
| trial1 | microgap | 0.672 (0th pctile) | 0.139 (0th pctile) | 0.979 (89th pctile) |
| trial2 | no-microgap | 0.673 (0th pctile) | -0.101 (0th pctile) | 0.979 (89th pctile) |
| trial2 | microgap | 0.666 (0th pctile) | -0.029 (0th pctile) | 0.994 (100th pctile) |
| trial3 | no-microgap | 0.680 (0th pctile) | 0.412 (2nd pctile) | 0.982 (92nd pctile) |
| trial3 | microgap | 0.673 (0th pctile) | 0.082 (0th pctile) | 0.991 (100th pctile) |

("pctile" = percentile of that composite's statistic within the 44-recording
real-vs-real distribution above; 50th = typical of real EEG, 0th/100th = below
or above the full real-vs-real range.)

**R1 (held-out redraws)** of the same manifests (B=150-200 redraws per
sentence, no-microgap condition, using epochs 1-18 instead of epoch 0):
spectral r rises from ~0.66-0.68 (epoch 0) to a stable **0.844-0.848** across
redraws (SD < 0.002 — the redraw distribution is tight; epoch 0 is not an
unusual draw, splicing itself is the limiting factor, not which repetition is
used), source-pattern rho likewise moves from the epoch-0 value toward
0.44-0.48 for trial1/trial3 (and stays near 0 for trial2, whose real
short-lag source pattern is close to chance-correlated with the reference
even for held-out real epochs — see per-sentence numbers in
`results.json["consistency"]["per_sentence"][*]["redraw_no_microgap"]`).

## Interpretation

1. **Metabolic readout (the manuscript's headline metric) is the most robust
   of the three domains.** CMRO2 spatial-profile correlation for synthetic
   composites (0.979-0.994) sits inside, or at the upper edge of, the
   real-vs-real range (0.835-0.988) for every sentence and both conditions.
   This is expected given the dependence finding above (Methods): the eight
   neurovascular variables — and the spatial *pattern* across channels in
   particular — are driven by the relative ranking of gamma power across
   channels, a coarse feature that splicing across phoneme recordings largely
   preserves.
2. **Fine time-frequency and instantaneous source detail are not preserved by
   splicing.** Spectral-shape correlation for every tested composite (0.66-
   0.68) sits below the entire real-vs-real range (0.94-1.00); redraws show
   this is a property of concatenating independently-recorded 1-2 s segments,
   not an artefact of using epoch 0 specifically. Source-space correlation is
   likewise below or at the very bottom of the real-vs-real range for 4 of 6
   composites, and indistinguishable from 0 for trial2.
3. **A 39-way nearest-centroid identification test** (band-power features,
   1000 permutations) confirms each phoneme recording's epoch 0 is
   identifiable above chance from the other 18 held-out epochs of the same
   phoneme (accuracy 0.128 vs. chance 0.026, permutation p=0.0010), at a level
   comparable to the ceiling achievable from real data alone
   (leave-one-epoch-out accuracy among the held-out epochs: 0.174). This
   supports that individual phoneme segments carry genuine, above-chance
   phoneme-specific spectral content — the limiting factor for consistency is
   the *concatenation*, not the individual segments.

**Bottom line for the manuscript's realism claims:** the data support the
claim that microgap insertion (and the composite-assembly procedure more
generally) changes simulated EEG-derived metabolic outputs, and that the
spatial pattern of the primary metabolic outcome (CMRO2) is not distinguishable
from real EEG by this analysis. They do **not** support a claim that the
composites reproduce real EEG's time-frequency structure or instantaneous
source pattern, and the manuscript language is revised accordingly (see
`docs/MANUSCRIPT_CHANGES.md`) to state the finding at the level it is
supported: an effect on simulated metabolic outputs, evaluated against a
same-pipeline real-vs-real baseline, with mixed results across analysis
domains reported rather than a single realism claim.

## Caveats

* One participant, one dataset (LaRocco et al., 2023); no independent
  biological reference exists for the tested sentences, consistent with the
  Future Work item added to the manuscript (validation against continuous
  imagined-speech EEG or natural pause data).
* The source-space comparison uses a from-scratch spherical forward model
  because MNE/fsaverage were not installable in this sandbox; absolute dSPM
  values are not expected to match the application's MNE-based figures, but
  the *relative* comparison (synthetic vs. real, same operator throughout) is
  unaffected by this substitution. Re-running `consistency.py` with an
  MNE-based `SourceImager` (same public interface: `power_map(x)`) once MNE is
  available is recommended as a confirmatory check and is noted as an action
  item in `docs/CORRECTIONS.md`.
* All p-values/percentiles here are descriptive of this dataset and this
  analysis pipeline; they are not claims about speech-EEG consistency in
  general.
